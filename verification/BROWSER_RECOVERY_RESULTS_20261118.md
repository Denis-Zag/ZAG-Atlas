# Поздний ответ после обрыва — 18 ноября 2026 года

## Основание

Я разобрал логи рабочего контейнера, которые прислал автор проекта. Два POST /kb/ask завершились HTTP 200 со статусом needs_review за 26,729 и 22,930 с. ProxyAPI вернул ответы за 7,723 и 5,516 с соответственно. Автор подтвердил, что оба результата появились в истории.

До завершения обработки браузер выполнил пять GET-проверок истории примерно за четыре секунды. Все они вернули 404, поскольку ответ ещё не был сохранён. Последняя проверка первого запроса завершилась в 10:42:15,589 UTC, а сам ответ — в 10:42:23,053 UTC. Интерфейс сообщал о неудаче раньше фактического завершения.

Первопричина обрыва соединения не установлена. Эти логи не подтверждают отказ Qdrant или ProxyAPI: оба запроса завершились, а ручная проверка объяснялась отсутствием подтверждения гарантии на монтаж. Разное число цитат в двух ответах само по себе не является сетевой ошибкой.

## Исправление

После сетевого обрыва или неполного JSON веб-панель до трёх минут проверяет историю по исходному X-Request-ID. Интервал — две секунды в первые 30 секунд, затем пять секунд. Каждый GET ограничен десятью секундами и остатком общего срока. HTTP 404/502/503/504 и сетевые ошибки допускают продолжение; HTTP 401/403 прекращают ожидание. POST повторно автоматически не отправляется.

Кнопка отправки остаётся заблокированной, повторное событие занятой формы игнорируется. После восстановления ответа сообщение об обрыве скрывается. По истечении срока показана инструкция проверить историю: система не утверждает, что сервер прекратил обработку.

## Проверки

Десять сценариев JavaScript проверяют реальные функции api/askWithRecovery с управляемыми часами и сетью: обычный ответ, обрыв на 15-й секунде с сохранением на 26,729-й, неполный JSON, временный HTTP 503 и сетевой отказ, окончание сессии, отказ в доступе, отсутствие результата весь срок, зависшее чтение, исчезновение старого предупреждения и повторное событие занятой формы. Во всех сценариях восстановления проверяется отсутствие повторного POST. Модель не вызывается.

JavaScript: 10/10. Общий unittest-прогон: 99 тестов за 46,056 с, без ошибок; один тест Python запускает эти десять сценариев Node.js. Проверена синтаксическая корректность static/app.js через node --check. Для JavaScript-проверок нужен Node.js; при его отсутствии соответствующий тест Python явно пропускается.
