# Итоговая сверка выпускного проекта — 18 ноября 2026 года

Я сверил комплект с исходным уроком «VPg09 — Выпускной проект по вайб-кодингу», дополнительным ТЗ варианта 5, согласованным сценарием ZAG Atlas и редакторскими решениями Дениса. Источник урока прочитан целиком; правила размещения видеоссылок сверены отдельно.

**Итог сверки:** программная часть и документация подготовлены; обе видеозаписи опубликованы и доступны по ссылкам. Длительности сообщил автор: демо — 5 мин 21 сек, защита — 9 мин 57 сек. [Репозиторий](https://github.com/Denis-Zag/ZAG-Atlas). Публичный серверный деплой по уроку не обязателен.

## Договорённости из обсуждений

| Решение | Сверка |
|---|---|
| Название, подпись, тёмно-зелёный интерфейс | ZAG Atlas; «Знания компании. Ответы с источниками»; текущие стили и принятые снимки |
| Одна компания на установку | Отдельная база и экземпляр; нет кнопки смены компании или обнуления. Профиль компании редактирует admin |
| Загрузка своих документов | Текстовая форма и PDF/DOCX/TXT/MD с предпросмотром, документ/источник имеет ID, дату и пользователя, добавившего материал |
| OCR | Tesseract и Poppler внутри Docker; локальное распознавание rus/eng, изображения семантически не анализируются; платного OCR API нет |
| Лимиты | По умолчанию название 200, вопрос 2 000, документ 100 000, контекст 20 000 символов, файл 10 МБ; настройка через интерфейс, без молчаливого обрезания |
| Qdrant | Включён в Compose, облачный аккаунт не требуется; эмбеддинги через ProxyAPI, гибридное объединение поиска, сохранённое обоснование на переформулировках |
| Технический отказ и нехватка знаний | Разные метки в карточке и списке; причина и request_id сохраняются. Проверенные сетевые отказы не считаются успехом |
| Персональные сотрудники | Создание только admin, временный пароль, обязательная смена, блокировка, сброс, собственная смена и выход. Права проверяет сервер |
| Поля пароля | Показ/скрытие, минимум 8 и максимум 128, сообщение несовпадения. Согласованный абзац находится в начале раздела входа README |
| Сроки сессии и защита подбора | Настраиваемые 30 минут/8 часов; пределы 10 на логин и 30 на IP в окне 15 минут описаны понятно |
| Восстановление единственного admin | Отдельная команда владельца, скрытый ввод, отзыв сессий, обязательная смена и атомарный аудит; 15 целевых тестов на временной базе |
| Сохранение ответа после обрыва | Исправленная версия интерфейса ожидает до трёх минут, не повторяет POST. Текущий HTTP-сервис отдаёт тот же JavaScript, что в исходниках |
| JSON и CSV | Оба формата, источники, кириллица и безопасность CSV проверены |
| Установщик сервера | install.sh и отдельный HTTPS-профиль не изменяют локальный Compose; локальные проверки пройдены. Реальный VPS/HTTPS не проверен, срок установки не обещается |
| Редакторские удаления | Удалённые разделы и фразы не восстановлены. Дата/курс REPORT, положение и текст абзаца о паролях проверены. Уточнения закреплены в AGENTS |
| Дальнейший деплой | Обсудить после комментариев преподавателя; не включать в обязательные препятствия сдаче |

## Повторные технические проверки

- 99 офлайн-тестов за 39,622 с, ошибок и пропусков нет. Один тест запускает десять сценариев JavaScript. [Журнал](FINAL_TEST_RESULTS_20261118.txt).
- pip check: конфликтов зависимостей нет. Python-файлы из состава публикации синтаксически разобраны без ошибок; node --check для app.js/passwords.js и bash -n install.sh пройдены.
- Локальные ссылки Markdown проверены; пропавших файлов не обнаружено. Известные рабочие секреты и типовые ключевые шаблоны в подготовленном составе и архиве не обнаружены. .env, .env.server, серверный файл домена и рабочая база в публичный архив не включены. Это целевая проверка, а не гарантия обнаружения любого возможного секрета.
- Работающий /health отвечает HTTP 200; /static/app.js отвечает HTTP 200 и совпадает с локальными исходниками, включая ожидание 180 секунд.
- Новых платных вызовов модели, переиндексации, сброса пароля или изменений рабочей базы при этой сверке я не выполнял. Docker и сохранённые данные не удалялись; предыдущий чистый запуск без причины не повторялся.
- Состав проверен временным Git-пробником внутри исключённого _rollback. По поручению автора PROJECT_SCOPE.md, STATUS.md и SUBMISSION_CHECKLIST.md исключены из публикации; ссылки на исключённые документы из публичного комплекта удалены.
